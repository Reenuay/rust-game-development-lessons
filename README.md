# Rust Game Development Lessons

Уроки по разработке игр на языке Rust — от простых концепций к более сложным
темам. Сайт собран на [Astro](https://astro.build) с темой
[Starlight](https://starlight.astro.build) для документации и
[Svelte](https://svelte.dev) для интерактивных компонентов внутри уроков.

## Стек

- **Astro** — генератор сайта, включает Vite как сборщик "из коробки"
- **Starlight** — тема документации: сайдбар, поиск, подсветка синтаксиса
- **Svelte** — интерактивные виджеты и демонстрации внутри уроков

## Структура проекта

```
.
├── src/
│   ├── content/
│   │   └── docs/          # страницы и уроки (Markdown/MDX)
│   │       └── lessons/   # уроки
│   └── content.config.ts  # схема коллекции документации Starlight
├── astro.config.mjs        # конфигурация Astro и Starlight
└── package.json
```

## Команды

Все команды выполняются из корня проекта в терминале:

| Команда           | Действие                                             |
| :---------------- | :---------------------------------------------------- |
| `npm install`     | Установить зависимости                                |
| `npm run dev`     | Запустить локальный сервер разработки на `localhost:4321` |
| `npm run build`   | Собрать статический сайт в `./dist/`                  |
| `npm run preview` | Локально просмотреть собранный сайт перед публикацией |
| `npm run check`   | Проверить проект (типы, синтаксис)                    |

До сих пор ты писал код в обычном текстовом редакторе и отдельно
открывал терминал, чтобы запустить `cargo run`. Дальше будет удобнее
делать это в одном окне — в редакторе кода **VS Code**: он подсвечивает
ошибки прямо во время письма кода и умеет открывать терминал внутри
себя.

## Установка

Зайди на [code.visualstudio.com](https://code.visualstudio.com), скачай
установщик для своей системы и запусти его, оставляя все настройки по
умолчанию.

## Расширение для Rust

Сам по себе VS Code ничего не знает про Rust — ему нужно расширение.

1. Открой VS Code.
2. Нажми на иконку квадратиков на левой панели (Extensions), либо
   сочетание `Ctrl + Shift + X` (`Cmd + Shift + X` на macOS).
3. В поиске введи `rust-analyzer`.
4. Нажми **Install** на первом результате.

`rust-analyzer` — официальное расширение для Rust. Оно подчёркивает
ошибки прямо в коде, подсказывает автодополнение и показывает типы
переменных, не дожидаясь `cargo run`.

## Открываем проект

Открой в VS Code папку `hello_world`, которую создал `cargo new` в
прошлом уроке: **File → Open Folder** и выбери эту папку.

## Терминал внутри VS Code

Не нужно переключаться в отдельное окно терминала — VS Code открывает
его прямо внутри себя:

- сочетание `` Ctrl + ` `` (клавиша с обратным апострофом, под `Esc`),
  на macOS — `` Cmd + ` ``;
- либо через меню **Terminal → New Terminal**.

Внизу появится окно терминала — в нём работают те же команды, что и
раньше: `cargo run`, `cargo new` и остальные. Дальше в уроках их можно
вводить прямо здесь, не покидая VS Code.

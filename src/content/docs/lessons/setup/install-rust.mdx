Rust ставится через официальный установщик `rustup`. Скачать его можно на
сайте [rustup.rs](https://rustup.rs).

<Tabs>
<TabItem label="Windows">

Rust на Windows использует линковщик (программу, которая собирает
скомпилированный код в готовый `.exe` файл) из **Visual Studio**. Без
него компьютер не сможет ничего запустить, поэтому его нужно поставить
первым, до Rust.

1. Открой страницу [Build Tools для Visual Studio](https://visualstudio.microsoft.com/ru/visual-cpp-build-tools/)
   и скачай установщик.
2. Запусти скачанный файл. Откроется окно с большим списком компонентов
   — поставь галочку на **"Разработка классических приложений на C++"**
   (Desktop development with C++) и нажми **"Установить"**.
3. Дождись окончания установки — это может занять несколько минут,
   скачивается довольно много данных. По завершении можно закрыть окно.
4. Открой [rustup.rs](https://rustup.rs) и скачай файл `rustup-init.exe`.
5. Запусти скачанный файл двойным щелчком.
6. Откроется чёрное окно терминала с текстом — нажми `Enter`, чтобы
   согласиться с установкой по умолчанию.
7. Дождись надписи `Rust is installed now. Great!` и закрой окно.

<Aside type="tip" title="Можно и без Visual Studio">

Есть более лёгкий вариант: вместо линковщика из Visual Studio
использовать линковщик GNU. Он весит в разы меньше и ставится прямо
через сам rustup — без установщика с сайта Microsoft.

Пропусти шаги 1–3 выше и сразу поставь Rust (шаги 4–7). Когда он
установлен, открой терминал и введи две команды:

```sh
rustup toolchain install stable-x86_64-pc-windows-gnu
rustup default stable-x86_64-pc-windows-gnu
```

Это переключит Rust на линковщик GNU, который он скачает и поставит
сам. Visual Studio после этого не понадобится.

</Aside>

## Проверка

Закрой терминал и открой его заново — это нужно, чтобы система увидела
новую программу. Введи команду:

```sh
rustc --version
```

Если в ответ появилась строка вида `rustc 1.xx.x (...)` — Rust установлен
и готов к работе.

## Ошибка `linker 'link.exe' not found` (Windows)

Если при `cargo run` появляется ошибка `linker 'link.exe' not found` —
значит, Rust уже поставлен, но пропущен шаг с Build Tools выше. Ставить
Rust заново не нужно, есть два варианта:

- **Поставить Build Tools.** Зайди на страницу [Build Tools для Visual Studio](https://visualstudio.microsoft.com/ru/visual-cpp-build-tools/),
  скачай и запусти установщик, поставь галочку на **"Разработка
  классических приложений на C++"** и нажми **"Установить"**.
- **Или переключиться на линковщик GNU** — он весит гораздо меньше и
  ставится без отдельного установщика. Введи в терминале:

  ```sh
  rustup toolchain install stable-x86_64-pc-windows-gnu
  rustup default stable-x86_64-pc-windows-gnu
  ```

После любого из вариантов открой терминал заново и попробуй `cargo run`
ещё раз.

Rust ставится через официальный установщик `rustup`. Скачать его можно на
сайте [rustup.rs](https://rustup.rs).

<Tabs>
<TabItem label="Windows">

Rust на Windows использует линковщик (программу, которая собирает
скомпилированный код в готовый `.exe` файл) — он идёт не вместе с
Rust, а отдельно, в составе Build Tools для Visual Studio.

1. Открой [rustup.rs](https://rustup.rs) и скачай файл `rustup-init.exe`.
2. Запусти скачанный файл двойным щелчком.
3. Откроется чёрное окно терминала с текстом — нажми `Enter`, чтобы
   согласиться с установкой по умолчанию.
4. Дождись надписи `Rust is installed now. Great!` и закрой окно.
5. Открой страницу [Build Tools для Visual Studio](https://visualstudio.microsoft.com/ru/visual-cpp-build-tools/)
   и скачай установщик.
6. Запусти скачанный файл. Откроется окно с большим списком компонентов
   — поставь галочку на **"Разработка классических приложений на C++"**
   (Desktop development with C++) и нажми **"Установить"**.
7. Дождись окончания установки — это может занять несколько минут,
   скачивается довольно много данных. По завершении можно закрыть окно.

</TabItem>
<TabItem label="macOS">

1. Открой приложение **Терминал**: нажми `Cmd + Пробел`, введи `Terminal`
   и нажми `Enter`.
2. Вставь в терминал команду ниже и нажми `Enter`:

   ```sh
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

3. Когда появится список опций, нажми `Enter`, чтобы выбрать установку
   по умолчанию.
4. Дождись надписи `Rust is installed now. Great!`.

</TabItem>
<TabItem label="Linux">

1. Открой терминал: обычно это сочетание `Ctrl + Alt + T`, либо найди
   приложение «Терминал» в меню программ.
2. Вставь в терминал команду ниже и нажми `Enter`:

   ```sh
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

3. Когда появится список опций, нажми `Enter`, чтобы выбрать установку
   по умолчанию.
4. Дождись надписи `Rust is installed now. Great!`.

## Проверка

Закрой терминал и открой его заново — это нужно, чтобы система увидела
новую программу. Введи команду:

```sh
rustc --version
```

Если в ответ появилась строка вида `rustc 1.xx.x (...)` — Rust установлен
и готов к работе.

## Ошибка `linker 'link.exe' not found` (Windows)

Если при `cargo run` появляется ошибка `linker 'link.exe' not found` —
значит, Rust уже поставлен, но не поставлены Build Tools для Visual
Studio из инструкции выше. Ставить Rust заново не нужно — нужно только
поставить их:

1. Зайди на страницу [Build Tools для Visual Studio](https://visualstudio.microsoft.com/ru/visual-cpp-build-tools/)
   и скачай установщик.
2. Запусти его, поставь галочку на **"Разработка классических
   приложений на C++"** (Desktop development with C++) и нажми
   **"Установить"**.
3. Дождись окончания установки.

После этого открой терминал заново и попробуй `cargo run` ещё раз.

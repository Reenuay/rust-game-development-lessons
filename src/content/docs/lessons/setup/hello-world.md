Cargo — это инструмент, который идёт вместе с Rust и создаёт для нас
проект со всем необходимым.

Открой терминал и введи команду:

```sh
cargo new hello_world
```

Появится папка `hello_world` с готовым проектом. Перейди в неё:

```sh
cd hello_world
```

## Запуск

Введи команду:

```sh
cargo run
```

В консоли появится:

```
Hello, world!
```

Это и есть готовая программа на Rust — Cargo сам её собрал и запустил.
Код программы находится в файле `src/main.rs`, если захочешь на него
посмотреть.

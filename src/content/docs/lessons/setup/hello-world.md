Cargo — это инструмент, который идёт вместе с Rust и создаёт для нас
проект со всем необходимым.

Открой терминал и введи команду:

```sh
cargo new hello_world
```

Появится папка `hello_world` с готовым проектом внутри. Вот что в ней:

```
hello_world/
├── Cargo.toml
└── src/
    └── main.rs
```

- `Cargo.toml` — описание проекта: имя, версия, какие библиотеки
  подключены. Пока туда заглядывать не нужно.
- `src/main.rs` — твой рабочий файл. Именно в нём ты будешь писать
  код весь этот курс.

Перейди в папку проекта:

```sh
cd hello_world
```

## Запуск

Введи команду:

```sh
cargo run
```

В консоли появится:

```
Hello, world!
```

Это и есть готовая программа на Rust — Cargo сам её собрал и запустил.

«Собрал» — важное слово. Перед тем как что-то запустить, Rust сначала
проверяет весь код на ошибки и переводит его в понятный компьютеру
вид — такая проверка называется **компиляцией**, а программа, которая
её делает, — **компилятором**. Если в коде есть ошибка, компилятор
найдёт её на этом шаге, и программа вообще не запустится — вместо
`Hello, world!` на экране появится текст ошибки. Это не то же самое,
что ошибка во время игры: компилятор останавливает тебя ещё до того,
как код вообще начал выполняться.

Если вместо этого Rust пожаловался на `linker 'link.exe' not found` —
ничего страшного, это известная ошибка на Windows, просто пропущен
один шаг при установке. Решение — в уроке [«Установка
Rust»](../install-rust/), там есть отдельный раздел именно про эту
ошибку.

## Код

Открой файл `src/main.rs` — внутри уже лежит весь код программы,
который ты только что запустил:

```rust title="src/main.rs"
fn main() {
    println!("Hello, world!");
}
```

- `fn main()` — точка входа: с этой функции начинается выполнение
  любой программы на Rust.
- `println!(...)` — выводит текст в консоль. Восклицательный знак
  означает, что это не обычная функция, а макрос — пока просто
  запомни, что для вывода текста он пишется именно так.

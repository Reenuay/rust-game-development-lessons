В уроке [«Расстояние»](../../basic/distance/) формула `(dx * dx + dy *
dy).sqrt()` просто появилась, без единого слова о том, откуда она
взялась. Разберёмся — с самого начала, по шагам.

## Прямоугольный треугольник, катеты, гипотенуза

`dx` — это шаг по горизонтали между двумя точками, `dy` — шаг по
вертикали. Если нарисовать оба этих шага и соединить начальную точку с
конечной прямой линией, получится треугольник: одна сторона идёт строго
вбок, другая строго вверх-вниз, а третья — наискось, напрямую от одной
точки к другой.

Угол между первыми двумя сторонами — ровно прямой угол, такой же, как в
углу листа бумаги или экрана. Треугольник, у которого есть такой угол,
называется **прямоугольным**. Две стороны, которые этот прямой угол
образуют (у нас это `dx` и `dy`), называются **катетами**. А третья
сторона — та самая, что идёт наискось, напрямую от начальной точки к
конечной, — называется **гипотенузой**.

Расстояние между двумя точками — это и есть длина гипотенузы вот такого
треугольника, где катеты — это `dx` и `dy`.

## Теорема Пифагора

Для **любого** прямоугольного треугольника — какой бы длины ни были его
катеты — есть правило, которое связывает все три стороны. Если катеты
назвать `a` и `b`, а гипотенузу — `c`, то:

```
c² = a² + b²
```

Квадрат гипотенузы равен сумме квадратов катетов. Это и называется
**теоремой Пифагора**, по имени человека, который её первым доказал.
Само по себе это довольно неожиданно — почему именно квадраты, а не,
скажем, просто сумма длин? Разберёмся, откуда это вообще берётся, а не
просто примем на слово.

## Один и тот же квадрат, две раскладки

Возьмём квадрат со стороной `a + b` и уложим в него четыре одинаковых
прямоугольных треугольника с катетами `a` и `b` — это можно сделать
двумя разными способами.

Первый способ: уложить треугольники по кругу, каждый повёрнут
относительно предыдущего. Тогда ровно в середине останется один
квадрат — повёрнутый, со стороной `c` (это и есть гипотенуза каждого
треугольника). Его площадь — `c²`.

Второй способ: сдвинуть те же четыре треугольника в два противоположных
угла большого квадрата. Тогда вместо одного повёрнутого квадрата
останутся два обычных — один со стороной `a`, другой со стороной `b`.
Их суммарная площадь — `a² + b²`.

Большой квадрат — один и тот же в обоих случаях. Четыре треугольника —
тоже одни и те же, просто переставленные. Значит, и то, что осталось
незакрытым, должно быть одинаковой площади при любой раскладке:

```
c² = a² + b²
```

Никакой тригонометрии — просто «переставили фигуры, площадь не
изменилась».

## Почему это и есть формула расстояния

`dx` и `dy` между двумя точками — это и есть катеты `a` и `b`: один шаг
по горизонтали, другой по вертикали. Расстояние между точками —
гипотенуза `c` того же самого прямоугольного треугольника. Значит:

```rust
let distance = (dx * dx + dy * dy).sqrt();
```

— это `c = √(a² + b²)`, просто записанное через `dx`/`dy` вместо
`a`/`b`, и с `.sqrt()` в конце, потому что теорема даёт `c²`, а нужен
сам `c`.

## Что здесь происходит

- **Прямоугольный треугольник** — треугольник с одним прямым углом.
  Две стороны, образующие этот угол, — **катеты**; третья, напротив
  прямого угла, — **гипотенуза**.
- **Теорема Пифагора**: для любого прямоугольного треугольника квадрат
  гипотенузы равен сумме квадратов катетов — `c² = a² + b²`.
- Четыре одинаковых прямоугольных треугольника укладывают один и тот
  же квадрат `(a + b) × (a + b)` двумя способами: либо оставляя один
  повёрнутый квадрат площадью `c²`, либо два обычных — площадью `a²`
  и `b²`.
- Большой квадрат и четыре треугольника не меняются между раскладками
  — поэтому оставшаяся площадь обязана совпадать: `c² = a² + b²`.
- `dx`, `dy` в коде — это катеты `a`, `b`; расстояние между точками —
  гипотенуза `c`. `(dx * dx + dy * dy).sqrt()` в уроке
  [«Расстояние»](../../basic/distance/) — ровно эта формула.

Хотим нарисовать пять кружков в ряд. Можно просто вызвать
`draw_circle` пять раз, каждый раз со своим `x`:

```rust
draw_circle(100.0, center_y, 20.0, YELLOW);
draw_circle(250.0, center_y, 20.0, YELLOW);
draw_circle(400.0, center_y, 20.0, YELLOW);
draw_circle(550.0, center_y, 20.0, YELLOW);
draw_circle(700.0, center_y, 20.0, YELLOW);
```

Работает — но если кружков нужно не пять, а сто, придётся писать сто
почти одинаковых строк, отличающихся только числом. Для этого и
существует `for`: одна и та же строка выполняется несколько раз
подряд, а вместо конкретного числа каждый раз подставляется новое.

## Что делает for

```rust
for i in 0..5 {
    // здесь i по очереди равно 0, 1, 2, 3, 4
}
```

`0..5` — это диапазон чисел от 0 до 5, не включая само 5 (та же идея,
что и в уроке [«Случайная точка»](../random/): верхняя граница никогда не
достигается). `for i in ...` берёт из этого диапазона числа по одному
и каждый раз выполняет тело цикла заново — сначала с `i = 0`, потом с
`i = 1`, и так до `i = 4`. Пять чисел — тело цикла выполнится пять
раз.

## Равномерно и по центру

Раз `i` меняется от кружка к кружку, можно посчитать его `x` прямо по
`i` — так, чтобы кружки легли ровным рядом по центру экрана. Сначала
нужен шаг — расстояние между соседними кружками. Чтобы пять кружков
равномерно заняли всю ширину `WIDTH`, эту ширину нужно поделить не на
пять, а на четыре — количество промежутков между пятью кружками
всегда на один меньше, чем самих кружков:

```rust
let step = WIDTH / (COUNT - 1) as f32;
```

Зная шаг, дальше просто: каждый следующий кружок сдвигается на один
шаг вправо от предыдущего, начиная от левого края `WIDTH`:

```rust
// Начинаем от левого края WIDTH и сдвигаемся на i шагов вправо.
let x = center_x - WIDTH / 2.0 + step * (i as f32);
```

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

// Сколько кружков рисуем.
const COUNT: usize = 5;
// Ширина, на которой они равномерно распределены.
const WIDTH: f32 = 600.0;

#[macroquad::main("Цикл for")]
async fn main() {
    // Шаг между соседними кружками: ширину делим на количество
    // промежутков между ними (кружков пять, промежутков — четыре).
    let step = WIDTH / (COUNT - 1) as f32;

    loop {
        clear_background(BLACK);

        // Центр экрана.
        let center_x = screen_width() / 2.0;
        let center_y = screen_height() / 2.0;

        // i по очереди принимает 0, 1, 2, 3, 4 — по разу на каждый кружок.
        for i in 0..COUNT {
            // Начинаем от левого края WIDTH и сдвигаемся на i шагов вправо.
            let x = center_x - WIDTH / 2.0 + step * (i as f32);
            draw_circle(x, center_y, 20.0, YELLOW);
        }

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Пять жёлтых кружков встают ровным рядом по центру экрана — так же,
как если бы мы вручную выписали все пять `draw_circle`, только теперь
это одна строка `draw_circle` внутри `for`:

## Что здесь происходит

- `for i in 0..COUNT` — повторяет тело цикла `COUNT` раз, давая `i`
  по очереди значения `0, 1, 2, 3, 4`.
- `i as f32` — `i` внутри `for` целое число (без дробной части, оно же
  просто счётчик), а `step` — `f32`. Умножать их напрямую нельзя,
  разные типы — поэтому `i` явно переводится в `f32` перед умножением
  (подробнее про целые числа и `as` — в уроке [«Целые
  числа»](../integers/)).
- `COUNT` и `WIDTH` — `const` вне `main`, как в уроке
  [«Константы»](../constants/): оба числа не меняются, пока программа
  работает.
- `step` посчитан один раз, до `loop`, — он не зависит от кадра, в
  отличие от `center_x`/`center_y`, которые пересчитываются заново
  каждый раз на случай, если экран поменяет размер (как в [«Если экран
  меняется»](../recompute/)).

До сих пор переменные вычислялись один раз и больше не менялись. А
что, если значение должно меняться, пока игра работает — например,
координата кружка, который должен ехать по экрану?

## mut

По умолчанию переменную в Rust нельзя изменить после создания. Чтобы
разрешить это, добавляется слово `mut`:

```rust
let mut x = screen_width() / 2.0;
```

Теперь `x` можно менять дальше по коду.

## Меняем значение

Изменить значение можно так:

```rust
x = x + 1.0;
```

Это значит: `x` становится равен своему же старому значению плюс
`1.0`. Для такой записи в Rust есть более короткий способ:

```rust
x += 1.0;
```

Работает точно так же, просто короче.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Изменяемые переменные")]
async fn main() {
    // Начинаем с центра экрана.
    let mut x = screen_width() / 2.0;
    let y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        x += 1.0;

        draw_circle(x, y, 100.0, YELLOW);

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Кружок сам, без нажатия каких-либо клавиш, едет вправо — потому что
`x` увеличивается на каждом кадре. Вот так это выглядит:

## Что здесь происходит

- `let mut x = ...;` — `mut` разрешает менять `x` после создания.
  Без него строка `x += 1.0;` не скомпилируется.
- `x += 1.0;` — на каждом кадре `x` становится на `1.0` больше,
  поэтому кружок непрерывно едет вправо.
- `y` осталась обычной, неизменяемой переменной — высота, на которой
  едет кружок, не меняется.

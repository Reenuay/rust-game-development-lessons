Хотим сделать неподвижную турель, которая умеет стрелять в сторону
курсора. Разложим задачу на то, что мы уже умеем:

- направление на курсор мы уже считаем в [«Направлении»](../direction/);
- сдвинуть точку по этому направлению — это [«Точка плюс
  вектор»](../vector/);
- отличить сам момент клика от того, что кнопка просто зажата, — этому
  учил [«Отрезок мышью»](../segment/) через `is_mouse_button_pressed`.

Складываем это вместе. Тело турели — обычный круг в центре экрана. У
неё есть глазик — ещё один кружок, смещённый от центра в сторону
курсора: центр плюс направление на курсор, растянутое до нужной длины
(та самая точка плюс вектор). Направление пересчитывается каждый
кадр, поэтому глазик постоянно довёрнут на курсор, как бы тот ни
двигался. А по клику из глазика вылетает пуля — в том направлении,
куда турель смотрела именно в момент выстрела.

## Пуля не следит за курсором

Это важное отличие от [«Погони за мышью»](../chase/): там направление
пересчитывалось каждый кадр, и кружок подруливал за курсором на лету.
Здесь направление пули запоминается один раз, в момент клика, и
дальше не трогается — как настоящая пуля, которая летит по прямой,
даже если ты потом уводишь мышь в сторону.

## Одна пуля — и точка

Если кликнуть ещё раз, пуля не добавляется, а просто появляется заново
— там, где сейчас глазик, и летит в новом направлении. Прошлая пуля,
где бы она ни была, никуда не сохраняется, а просто перезаписывается.
Хранить сразу несколько пуль означало бы помнить список из
неизвестного заранее количества объектов — а с этим мы разберёмся в
одном из следующих уроков, когда научимся создавать много объектов по
клику. Пока что — одна пуля, и этого достаточно, чтобы разобраться,
как вообще устроен выстрел.

По той же причине мы не проверяем, улетела ли пуля за край экрана: с
одной пулей это не мешает ничему на экране, а новый клик всё равно
перезапускает её с нуля.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Турель стреляет")]
async fn main() {
    // Направление глазика по умолчанию — ещё до первого движения мыши.
    let mut direction_x = 1.0;
    let mut direction_y = 0.0;

    // Пока не было клика — пули на экране нет.
    let mut bullet_flying = false;
    let mut bullet_x = 0.0;
    let mut bullet_y = 0.0;
    let mut bullet_direction_x = 0.0;
    let mut bullet_direction_y = 0.0;

    loop {
        clear_background(BLACK);

        // Турель стоит в центре экрана.
        let center_x = screen_width() / 2.0;
        let center_y = screen_height() / 2.0;

        // Координаты курсора.
        let (mouse_x, mouse_y) = mouse_position();

        // Направление от турели к курсору (как в «Направлении»).
        let dx = mouse_x - center_x;
        let dy = mouse_y - center_y;
        let distance = (dx * dx + dy * dy).sqrt();

        // Курсор не точно в центре — можно обновить направление.
        if distance > 0.0 {
            direction_x = dx / distance;
            direction_y = dy / distance;
        }

        // Глазик — точка плюс вектор (как в «Точке плюс векторе»):
        // центр турели плюс направление, растянутое на 25 пикселей.
        let eye_x = center_x + direction_x * 25.0;
        let eye_y = center_y + direction_y * 25.0;

        // Клик — новый выстрел: пуля стартует из глазика, а направление
        // полёта фиксируется прямо сейчас и больше не меняется.
        if is_mouse_button_pressed(MouseButton::Left) {
            bullet_flying = true;
            bullet_x = eye_x;
            bullet_y = eye_y;
            bullet_direction_x = direction_x;
            bullet_direction_y = direction_y;
        }

        // Пуля летит своим зафиксированным направлением, не подстраиваясь
        // под курсор — в отличие от «Погони за мышью».
        if bullet_flying {
            bullet_x += bullet_direction_x * 10.0;
            bullet_y += bullet_direction_y * 10.0;
        }

        // Тело турели.
        draw_circle(center_x, center_y, 40.0, BLUE);
        // Глазик — смотрит на курсор.
        draw_circle(eye_x, eye_y, 10.0, WHITE);
        // Пуля — рисуем, только если уже был хоть один клик.
        if bullet_flying {
            draw_circle(bullet_x, bullet_y, 8.0, YELLOW);
        }

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Подвигай мышь — глазик поворачивается вслед за курсором. Кликни — из
глазика вылетит жёлтая пуля и полетит по прямой. Кликни ещё раз, пока
первая пуля в полёте, — она тут же появится заново из текущего
положения глазика:

## Что здесь происходит

- `direction_x`, `direction_y` — направление турели на курсор,
  обновляется каждый кадр, пока курсор не в центре (та же защита от
  деления на ноль, что и в [«Делении на ноль»](../divide-by-zero/)).
- `eye_x`, `eye_y` — глазик, всегда пересчитывается заново: центр
  турели плюс направление, растянутое до 25 пикселей.
- `bullet_direction_x`, `bullet_direction_y` — направление пули,
  наоборот, запоминается только один раз, в момент клика, и после
  этого не пересчитывается — поэтому пуля летит прямо, а не
  довёрнутая на курсор.
- `bullet_flying` — пока `false`, пуля вообще не рисуется; клик
  включает его раз и навсегда, а дальше только пересоздаёт пулю
  заново с текущей позиции глазика.

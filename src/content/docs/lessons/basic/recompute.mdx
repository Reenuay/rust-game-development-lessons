В уроке [«Движение»](../movement/) мы вычисляли центр экрана один раз,
до `loop`, и дальше просто им пользовались — это выгоднее, чем каждый
кадр заново делить `screen_width()` на 2. Но у этого есть цена: если
во время игры окно вдруг изменит размер (игрок потянул за угол,
свернул и развернул окно, повернул телефон), `center_x` и `center_y`
так и останутся такими, какими были при запуске. Экран стал другим —
а переменная нет.

## Запомнили один раз

```rust
use macroquad::prelude::*;

#[macroquad::main("Центр")]
async fn main() {
    // Считаем один раз, до loop.
    let center_x = screen_width() / 2.0;
    let center_y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        draw_circle(center_x, center_y, 60.0, YELLOW);

        next_frame().await;
    }
}
```

Пока размер окна не меняется, всё в порядке. Но измени окно во время
игры — и кружок больше не будет по центру: `center_x` и `center_y`
посчитаны один раз и с тех пор не трогались, а `screen_width()` с
`screen_height()` тем временем уже вернули бы другие числа.

## Считаем заново каждый кадр

```rust
use macroquad::prelude::*;

#[macroquad::main("Центр")]
async fn main() {
    loop {
        clear_background(BLACK);

        // Считаем заново на каждом кадре — значение всегда свежее.
        let center_x = screen_width() / 2.0;
        let center_y = screen_height() / 2.0;

        draw_circle(center_x, center_y, 60.0, YELLOW);

        next_frame().await;
    }
}
```

Здесь `center_x` и `center_y` — уже внутри `loop`, поэтому считаются
заново на каждом кадре. Экран поменялся — на следующем же кадре
`screen_width()` вернёт новое число, и центр пересчитается вместе с
ним. Кружок остаётся по центру, каким бы ни было окно.

## Что здесь происходит

- Значение, которое не может измениться за время игры (радиус
  кружка, к примеру), можно спокойно вычислить один раз до `loop` —
  так мы и делали раньше.
- А то, что может измениться уже после запуска — размер экрана,
  позиция мыши и так далее, — стоит считать внутри `loop`, заново на
  каждом кадре, иначе программа будет пользоваться уже устаревшим
  числом.
- `mouse_position()` из урока [«Координаты мыши»](../mouse-position/)
  мы, кстати, уже всегда вызывали именно внутри `loop` — курсор
  двигается постоянно, и вне цикла эта функция была бы бесполезна.

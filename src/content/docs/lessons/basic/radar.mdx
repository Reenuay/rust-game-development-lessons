В уроке [«Расстояние»](../distance/) мы научились находить число —
сколько пикселей между двумя точками. Само по себе это число мало
что значит, но его можно **сравнить** с другим числом — точно тем же
`if`, что и в уроке [«Иначе»](../else/), только вместо "нажата ли
кнопка" теперь условие "расстояние меньше радиуса".

Так работает обнаружение в играх: у турели есть радиус обзора, и если
игрок оказался ближе этого радиуса — турель его заметила.

```rust
if distance < radius {
    // игрок рядом
} else {
    // игрок далеко
}
```

## Что здесь происходит

- `distance` — то же самое расстояние от центра до курсора, что и в
  прошлом уроке.
- `if distance < RADIUS { ... } else { ... }` — сравнивает расстояние
  с радиусом: `<` значит "меньше". Если курсор ближе радиуса — условие
  верно, и турель рисуется красной; если дальше — синей.
- `RADIUS` написана заглавными буквами и объявлена вне `main` — как в
  уроке [«Константы»](../constants/): её значение не зависит от
  кадра, так
  что пересчитывать её внутри `loop` незачем.
- Серый контур сам по себе ничего не проверяет, он просто рисует
  границу — чтобы было видно, где именно проходит тот самый радиус,
  с которым сравнивается расстояние.

Давай нарисуем полоску здоровья. Для неё хватит двух прямоугольников,
которые мы уже умеем рисовать по уроку
[«Прямоугольник»](../rectangle/).

## Две полоски

Первая, серая, рисуется целиком: она показывает всё здоровье, которое
вообще может быть. Вторая, цветная, лежит поверх неё и показывает,
сколько здоровья осталось. Её рисуем позже серой, поэтому она
оказывается сверху, как в уроке [«Порядок отрисовки»](../draw-order/).

Обе полоски начинаются в одном месте и одной высоты. Отличается только
ширина: у цветной она зависит от здоровья.

## Доля здоровья

Чтобы найти ширину цветной полоски, нужна доля здоровья от 0 до 1, как
в уроке [«Доля от 0 до 1»](../fractions/). Делим текущее здоровье на
максимальное. Осталось 50 из 100, значит доля равна `0.5`, и цветная
полоска вдвое короче серой. Это те же проценты из урока
[«Проценты»](../percentages/), только поделённые на сто.

```rust
// Доля здоровья от 0 до 1: осталось 50 из 100 — получится 0.5.
let fraction = health / MAX_HEALTH;

// Серая подложка — вся полоска целиком.
draw_rectangle(BAR_X, BAR_Y, BAR_WIDTH, BAR_HEIGHT, GRAY);
// Цветная часть — столько от всей ширины, сколько осталось здоровья.
draw_rectangle(BAR_X, BAR_Y, BAR_WIDTH * fraction, BAR_HEIGHT, GREEN);
```

## Здоровье по клику

Текущее здоровье меняется, поэтому это переменная с `mut`, как в
уроке [«Изменяемые переменные»](../mutability/). Клик, как в уроке
[«Клик мышью»](../mouse-click/), отнимает `DAMAGE`. Когда здоровья уже
нет, следующий клик возвращает полное. Так полоска успевает показать
«пусто», а не перескакивает сразу на максимум:

```rust
if health <= 0.0 {
    // Здоровья уже нет — возвращаем полное.
    health = MAX_HEALTH;
} else {
    // Отнимаем урон. max(0.0) не даёт здоровью уйти ниже нуля.
    health = (health - DAMAGE).max(0.0);
}
```

`.max(0.0)` берёт большее из двух чисел, как в уроке
[«Радиус мышью»](../drag-radius/). Если поменять `DAMAGE` на число,
которое не делит 100 нацело, без этого здоровье ушло бы ниже нуля, а
ширина цветной полоски стала бы отрицательной.

## Цвет от здоровья

Когда здоровья мало, полоска должна краснеть. Цвет выбирает `if`, как в
уроке [«if как значение»](../if-value/):

```rust
// Здоровья достаточно — зелёная полоска, мало — красная.
let color = if fraction > LOW_HEALTH { GREEN } else { RED };
```

`LOW_HEALTH` — доля, ниже которой здоровье считается низким. `0.3`
значит 30 процентов. Серая подложка не меняется, цвет выбирается только
для цветной части.

## Что здесь происходит

- `MAX_HEALTH`, `DAMAGE`, `LOW_HEALTH` и размеры полоски — константы,
  как в уроке [«Константы»](../constants/): они не меняются от кадра к
  кадру.
- `health` — текущее здоровье. Это единственное, что меняется в
  программе.
- `fraction = health / MAX_HEALTH` — доля здоровья от 0 до 1. По ней
  считается ширина цветной полоски.
- Серый прямоугольник шириной `BAR_WIDTH` рисуется целиком, а цветной
  шириной `BAR_WIDTH * fraction` рисуется поверх него.
- На клик здоровье уменьшается на `DAMAGE`, а когда оно кончилось,
  возвращается к максимуму.
- `.max(0.0)` не даёт здоровью стать отрицательным.
- `let color = if fraction > LOW_HEALTH { GREEN } else { RED };` выбирает
  цвет один раз, а нарисовать им можно что угодно.

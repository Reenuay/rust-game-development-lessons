**Индекс** уже встречался в уроке [«Список кружков»](../list/) — это
просто номер элемента по порядку, начиная с `0`: `points[0]` — первый
элемент, `points[1]` — второй, и так далее. Тот же приём работает и
здесь: `circles[0]` — первый кружок в списке.

В уроке [«Кружки исчезают»](../circles-vanish/) клик убирал кружок из
списка, и список пересобирался заново, без него. А что, если нужно не
просто убирать кружки, а ещё и **запомнить** один конкретный — скажем,
турель держит его на прицеле, и это должен быть именно он, кадр за
кадром, что бы ни происходило с остальными? Цвет и радиус каждого
кружка тут ни при чём, так что для этого урока хватит одного
фиксированного радиуса, одного цвета и обычных пар `(f32, f32)`, как
в [«Списке кружков»](../list/) — без отдельной структуры `Circle`.

Самый очевидный способ запомнить один конкретный кружок — запомнить
его индекс:

```rust
// "Запомненный" кружок — просто его номер в списке, четвёртый по счёту.
const TARGET_INDEX: usize = 3;
```

## Подписываем кружки их индексом

Чтобы сразу видеть, у какого кружка какой индекс, подпишем каждый
его номером — тем же `draw_text`, что и в [«Тексте на
экране»](../text-on-screen/), переведя число в строку через
`.to_string()`, как в [«Строках»](../strings/):

```rust
// Рисуем каждый кружок и подписываем его индексом в списке.
for i in 0..circles.len() {
    let (x, y) = circles[i];
    draw_circle(x, y, RADIUS, YELLOW);
    draw_text(&i.to_string(), x, y, 128.0, BLACK);
}
```

А вокруг «запомненного» кружка — ещё и кольцо:

```rust
if TARGET_INDEX < circles.len() {
    let (x, y) = circles[TARGET_INDEX];
    draw_circle_lines(x, y, RADIUS + 10.0, 4.0, WHITE);
}
```

Проверка `TARGET_INDEX < circles.len()` нужна, потому что кружков со
временем может остаться меньше, чем `TARGET_INDEX` — а обратиться по
индексу, которого в списке уже нет, нельзя: программа просто упадёт с
ошибкой. Поэтому сначала проверяем, что место под этим номером вообще
существует, и только потом туда обращаемся.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

// Радиус один и тот же у всех кружков — фиксированный, как в уроке «Константы».
const RADIUS: f32 = 60.0;

// Своя функция: расстояние между двумя точками, как в уроке «Расстояние».
fn distance(from_x: f32, from_y: f32, to_x: f32, to_y: f32) -> f32 {
    let dx = to_x - from_x;
    let dy = to_y - from_y;
    (dx * dx + dy * dy).sqrt()
}

// "Запомненный" кружок — просто его номер в списке, четвёртый по счёту.
const TARGET_INDEX: usize = 3;

#[macroquad::main("Ловушка индекса")]
async fn main() {
    // Начальный набор кружков — случайные позиции, одного радиуса и цвета.
    let mut circles: Vec<(f32, f32)> = Vec::new();
    for _ in 0..8 {
        circles.push((
            rand::gen_range(40.0, screen_width() - 40.0),
            rand::gen_range(40.0, screen_height() - 40.0),
        ));
    }

    loop {
        clear_background(BLACK);

        // Клик только что случился — убираем кружки под курсором.
        if is_mouse_button_pressed(MouseButton::Left) {
            let (mouse_x, mouse_y) = mouse_position();

            // Новый пустой список — специально для кружков, которые стоит оставить.
            let mut kept_circles: Vec<(f32, f32)> = Vec::new();

            // Забираем старый список circles в собственность.
            for (x, y) in circles {
                let clicked_inside = distance(mouse_x, mouse_y, x, y) < RADIUS;

                if !clicked_inside {
                    kept_circles.push((x, y));
                }
            }

            // На этот кадр circles становится тем, что мы только что собрали.
            circles = kept_circles;
        }

        // Рисуем каждый кружок и подписываем его индексом в списке.
        for i in 0..circles.len() {
            let (x, y) = circles[i];
            draw_circle(x, y, RADIUS, YELLOW);
            draw_text(&i.to_string(), x, y, 128.0, BLACK);
        }

        // Кольцо вокруг "запомненного" кружка — только по номеру в списке.
        if TARGET_INDEX < circles.len() {
            let (x, y) = circles[TARGET_INDEX];
            draw_circle_lines(x, y, RADIUS + 10.0, 4.0, WHITE);
        }

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Один из кружков обведён белым кольцом — это и есть `TARGET_INDEX`, и
число на нём совпадает с номером кольца. Кликни по **другому**
кружку, который на экране левее или выше него (то есть раньше попал
в список), чтобы убрать его — номера на всех кружках после него
сдвинутся на единицу, а кольцо останется на той же позиции `3`, но
уже вокруг другого кружка:

## Что здесь происходит

- Индекс — номер элемента в списке, начиная с `0`, тот же, что и в
  [«Списке кружков»](../list/).
- `for i in 0..circles.len()` перебирает все позиции списка по
  номерам, а не сами кружки — поэтому у нас на руках есть и сам
  кружок (`circles[i]`), и его индекс (`i`) одновременно.
- Число на кружке — его `i` на этот кадр, переведённое в строку через
  `.to_string()`. Это просто позиция, а не что-то, что принадлежит
  конкретному кружку: у одного и того же кружка число меняется, если
  перед ним в списке что-то исчезло.
- Кольцо честно рисуется вокруг того, что сейчас находится по индексу
  `TARGET_INDEX`, — программа делает ровно то, что написано, просто то,
  что написано, оказалось не тем, что имелось в виду.
- Если удалить достаточно кружков, `TARGET_INDEX` вообще выйдет за
  пределы списка — тогда кольцо просто пропадёт, потому что
  `TARGET_INDEX < circles.len()` станет `false`.

Индекс — это место в списке, а не личность кружка. В следующем уроке
разберёмся, как запоминать именно кружок, а не его текущую позицию.

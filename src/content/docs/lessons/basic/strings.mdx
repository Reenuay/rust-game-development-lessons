В уроке [«Hello World»](../../setup/hello-world/) уже была строка —
`"Hello, world!"`, просто тогда было не до объяснений, нужно было
только запустить программу. Сейчас разберёмся, что это такое.

## Что такое строка

Строка — это просто текст: какие угодно символы в кавычках. До сих
пор в коде встречались только числа (`f32`) да `bool` — строка это
новый вид значения, для текста, а не для счёта:

```rust
let greeting = "Привет!";
```

Даже если внутри кавычек цифры, это всё равно текст, а не число:
`"42"` нельзя сложить с другим числом, как обычное `42`, — для Rust
это просто два символа, `'4'` и `'2'`, а не число сорок два.

## Число в строку

Чтобы показать число вместе с текстом — например, «кружков: 5» —
само число сначала нужно превратить в строку. Для этого у чисел есть
метод `.to_string()`:

```rust
let count = 5;
let count_text = count.to_string();
```

Было число `5`, стало — строка `"5"`. Выглядит так же, но это уже не
число: умножить его больше нельзя, зато можно показать рядом с другим
текстом.

## Печатаем строку с числом внутри

`println!` из «Hello World» выводил готовый текст целиком. А если
нужно вставить в текст ещё и значение переменной, внутри строки
пишут пустые фигурные скобки `{}` — туда и подставится следующий
аргумент:

```rust
println!("Кружков: {}", count_text);
```

В консоль попадёт `Кружков: 5` — текст и значение `count_text` вместе,
на месте `{}`.

## Код

```rust title="src/main.rs"
fn main() {
    let count = 5;
    let count_text = count.to_string();

    println!("Кружков: {}", count_text);
}
```

Запусти как обычно:

```sh
cargo run
```

В консоли появится:

```
Кружков: 5
```

## Что здесь происходит

- Строка — текст в кавычках, отдельный от чисел вид значения, даже
  если внутри кавычек одни цифры.
- `.to_string()` превращает число в строку с тем же самым
  изображением — `5` становится `"5"`.
- `{}` внутри строки у `println!` — место, куда подставляется
  следующий аргумент после запятой.

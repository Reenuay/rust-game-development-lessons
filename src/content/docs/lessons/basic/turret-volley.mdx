В уроке [«Турель стреляет»](../turret/) была ровно одна пуля: новый клик не
добавлял вторую, а просто переставлял ту же самую на новое место,
стирая предыдущий выстрел. Теперь, когда мы умеем создавать объекты
прямо в процессе работы программы — через `Vec` и `.push()`, как в
уроке [«Список кружков»](../list/) — можно накапливать пули, а не
только держать одну.

## Переиспользуем direction

Внутри `loop` турели всегда был кусок с `dx`, `dy` и `sqrt`, чтобы
посчитать направление от центра к мыши. Мы уже выносили этот же самый
расчёт в отдельную функцию `direction` в уроке [«Свои
функции»](../functions/) — пересчитывать его заново тут незачем,
просто вызываем готовую функцию:

```rust
let (direction_x, direction_y) = direction(center_x, center_y, mouse_x, mouse_y);
```

Так в `loop` не остаётся лишней математики, и весь урок можно
посвятить тому, что здесь действительно новое, — списку пуль.

## Пуля как структура

Раньше положение и направление пули жили в четырёх отдельных
переменных: `bullet_x`, `bullet_y`, `bullet_direction_x`,
`bullet_direction_y`. Соберём их в одну структуру — та же идея, что и
`Circle` в уроке [«Свои структуры»](../structs/):

```rust
struct Bullet {
    x: f32,
    y: f32,
    direction_x: f32,
    direction_y: f32,
}
```

Список пуль — `Vec<Bullet>`, сначала пустой:

```rust
let mut bullets: Vec<Bullet> = Vec::new();
```

По клику вместо того, чтобы переставлять одну пулю, добавляем в конец
списка новую:

```rust
bullets.push(Bullet {
    x: eye_x,
    y: eye_y,
    direction_x,
    direction_y,
});
```

## Двигаем каждую пулю на месте

В уроке [«Список кружков»](../list/) цикл `for &(x, y) in &points` только
читал точки, чтобы их нарисовать, — сами точки никогда не менялись.
Здесь по-другому: `x` и `y` каждой пули должны **меняться** на каждом
кадре, ведь пуля летит. Для этого нужен `&mut bullets` вместо
`&bullets`:

```rust
for bullet in &mut bullets {
    bullet.x += bullet.direction_x * SPEED;
    bullet.y += bullet.direction_y * SPEED;
    draw_circle(bullet.x, bullet.y, 8.0, YELLOW);
}
```

`&bullets` дал бы доступ только для чтения — менять `bullet.x` внутри
такого цикла не вышло бы. `&mut bullets` разрешает и читать, и
записывать: обновляем позицию каждой пули и сразу рисуем её в новом
месте, одним и тем же циклом.

Пули, улетевшие за край экрана, никуда не деваются — список продолжает
расти, сколько бы ни было кликов. Это не забытая деталь, а осознанное
упрощение: с этим разберёмся в одном из следующих уроков.

## Что здесь происходит

- `direction(center_x, center_y, mouse_x, mouse_y)` — та же функция,
  что и в уроке [«Свои функции»](../functions/), просто вызванная
  здесь: избавляет `loop` от повторного расчёта `dx`, `dy` и `sqrt`.
- `struct Bullet { x, y, direction_x, direction_y }` — то, что раньше
  было четырьмя отдельными переменными, теперь одна структура, как
  `Circle`.
- `Vec<Bullet>` — список пуль, который растёт по одной с каждым
  кликом, та же идея, что и `Vec<(f32, f32)>` в уроке [«Список
  кружков»](../list/).
- `bullets.push(Bullet { ... })` добавляет новую пулю в конец списка,
  не трогая уже существующие — в отличие от урока [«Турель
  стреляет»](../turret/), где клик просто переписывал единственную
  пулю.
- `for bullet in &mut bullets` — мутабельная ссылка нужна, потому что
  тело цикла меняет `bullet.x` и `bullet.y`, а не только читает их.
- Направление у каждой пули своё и зафиксировано в момент выстрела —
  та же идея, что и в уроке [«Турель стреляет»](../turret/): пуля
  летит по прямой, не подстраиваясь под мышь.
- Список пуль ничем не ограничен и никогда не уменьшается — сколько
  кликов, столько и пуль в списке, даже если их давно не видно на
  экране.

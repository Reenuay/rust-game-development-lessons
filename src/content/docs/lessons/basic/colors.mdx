## Массив цветов

Набор цветов, из которых выбираем, не меняется во время работы
программы — он известен заранее и раз и навсегда. Вот тут массив
подходит идеально: его фиксированная длина, которая мешала в уроке
[«Список кружков»](../list/), здесь наоборот на пользу — все цвета
собраны в одном месте, а не разбросаны по отдельным переменным.

```rust
const COLORS: [Color; 4] = [YELLOW, RED, GREEN, BLUE];
```

`Color` — тип, который у нас давно на виду: это тип значений вроде
`YELLOW` и `BLACK`, просто раньше не было повода называть его по
имени.

У массива есть метод `.len()` — он возвращает, сколько элементов
внутри. Число `4` в типе `[Color; 4]` всё-таки пришлось написать
руками — это часть объявления массива, тут никуда не деться. Но это
единственное место, где оно встречается: `.len()` в остальном коде
читает длину прямо из `COLORS`, а не хранит её отдельно, как хранил
бы отдельный `const COUNT`. Добавишь пятый цвет — поправишь только
`[Color; 4]` на `[Color; 5]`, а `.len()` везде сам вернёт уже новое
число, без правок где-либо ещё.

## Случайный индекс

Раньше `rand::gen_range` выбирал случайную координату на экране (в
[«Случайной точке»](../random/)). Здесь тот же `gen_range` выбирает
случайный **индекс** элемента в массиве — число от `0` до
`COLORS.len() - 1`, тот же принцип «до, но не включая», что и в
`0..COUNT` из [«Скольких угодно кружков»](../any-count/):

```rust
let index = rand::gen_range(0, COLORS.len());
let color = COLORS[index];
```

`COLORS[index]` — доступ к элементу массива по индексу, ровно тот
самый случайно выбранный цвет.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

// Фиксированный список цветов, из которого выбираем случайный.
const COLORS: [Color; 4] = [YELLOW, RED, GREEN, BLUE];

#[macroquad::main("Разноцветные кружки")]
async fn main() {
    // Список кружков: координаты клика и выбранный для него цвет.
    let mut circles: Vec<(f32, f32, Color)> = Vec::new();

    loop {
        clear_background(BLACK);

        // Кнопка мыши только что нажата — новый кружок со случайным цветом.
        if is_mouse_button_pressed(MouseButton::Left) {
            let (x, y) = mouse_position();
            // Случайный индекс от 0 до длины списка COLORS.
            let index = rand::gen_range(0, COLORS.len());
            circles.push((x, y, COLORS[index]));
        }

        // Рисуем каждый кружок его собственным цветом.
        for &(x, y, color) in &circles {
            draw_circle(x, y, 20.0, color);
        }

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Кликай по экрану — каждый новый кружок получает случайный цвет из
четырёх заданных. Попробуй прямо здесь:

## Что здесь происходит

- `const COLORS: [Color; 4] = [...]` — массив из четырёх цветов,
  собранных в одном месте, а не в четырёх отдельных переменных.
- `COLORS.len()` — длина массива, `4`, взятая из самого массива, а не
  прописанная отдельно.
- `rand::gen_range(0, COLORS.len())` возвращает случайный индекс от
  `0` до `COLORS.len() - 1` — та же функция, что и раньше, просто
  диапазон теперь подобран под размер массива.
- `COLORS[index]` — доступ к элементу массива по индексу, тот самый
  случайно выбранный цвет.
- `Vec<(f32, f32, Color)>` — кортеж вырос до трёх элементов: теперь
  каждый кружок хранит ещё и свой цвет вместе с координатами.

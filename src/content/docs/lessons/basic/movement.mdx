Всё для этого уже есть по отдельности: `is_key_down` из урока про ввод
говорит, какая клавиша зажата, а `x` и `y` из урока про координаты
говорят, где рисовать фигуру. Остаётся соединить одно с другим: пока
клавиша зажата — понемногу менять `x` или `y`.

## Изменяемая переменная

Раньше `x` и `y` вычислялись один раз и больше не менялись. Теперь им
нужно меняться каждый кадр — а обычная переменная (`let`) в Rust после
создания не меняется. Чтобы разрешить изменения, добавляется слово
`mut`:

```rust
let mut x = screen_width() / 2.0;
```

Дальше в коде можно писать `x = x + 1.0;` (или короче — `x += 1.0;`) и
значение действительно изменится. Без `mut` Rust не разрешит так
сделать — если переменная не собиралась меняться, случайное изменение
скорее всего ошибка, и Rust ловит её ещё до запуска игры.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Движение")]
async fn main() {
    let mut x = screen_width() / 2.0;
    let mut y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        if is_key_down(KeyCode::Up) {
            y -= 8.0;
        }
        if is_key_down(KeyCode::Down) {
            y += 8.0;
        }
        if is_key_down(KeyCode::Left) {
            x -= 8.0;
        }
        if is_key_down(KeyCode::Right) {
            x += 8.0;
        }

        draw_circle(x, y, 100.0, YELLOW);

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Стрелки двигают кружок в свою сторону, и пока клавиша зажата, он едет
дальше. Вот так это выглядит — можно попробовать прямо здесь (клик по

## Что здесь происходит

- `let mut x = ...;` — `mut` разрешает менять `x` после создания.
  Без него следующая строка `x -= 8.0;` не скомпилируется.
- `y -= 8.0;` — то же самое, что `y = y - 8.0;`, то есть "подвинуть
  `y` на 8 пикселей в сторону меньших значений", а раз ось `y` растёт
  вниз, это движение вверх по экрану.
- Число `8.0` — скорость движения в пикселях за кадр — написано прямо
  в коде четыре раза, по разу на каждое направление. Это не очень
  удобно: если захочется сделать кружок быстрее, придётся менять все
  четыре места сразу. Один из следующих уроков покажет, как это
  исправить.

`if` уже знаком по уроку [«Клик мышью»](../mouse-click/): код внутри
выполняется, только если условие верно. У `if` есть пара — `else`.
Код внутри `else` выполняется ровно в противоположном случае: только
когда условие **не** верно.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Иначе")]
async fn main() {
    // Центр экрана — считаем один раз, до loop.
    let center_x = screen_width() / 2.0;
    let center_y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        if is_mouse_button_down(MouseButton::Left) {
            // Кнопка нажата — рисуем жёлтый кружок.
            draw_circle(center_x, center_y - 150.0, 80.0, YELLOW);
        } else {
            // Не нажата — рисуем красный.
            draw_circle(center_x, center_y - 150.0, 80.0, RED);
        }

        // А этот рисуем всегда, вне зависимости от кнопки.
        draw_circle(center_x, center_y + 150.0, 80.0, BLUE);

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

Сверху — кружок, который меняет цвет: красный, пока кнопка мыши не
нажата, и жёлтый, пока она зажата. Снизу — синий кружок, который
просто всегда на месте. Попробуй прямо здесь:

## Что здесь происходит

- `if is_mouse_button_down(...) { ... } else { ... }` — выполняется
  ровно один из двух блоков, никогда не оба сразу: если условие
  верно — первый, если нет — второй.
- Пока кнопка не нажата, верхний кружок красный: выполняется именно
  блок `else`, потому что условие в `if` ложно.
- Нижний, синий, кружок нарисован вообще без всякого `if` — просто
  отдельной строчкой после условия. Она выполняется на каждом кадре
  без исключений, независимо от того, нажата кнопка или нет.

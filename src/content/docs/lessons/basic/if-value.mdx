Давай сделаем так, чтобы ветки `if` не рисовали, а только выбирали
цвет. В уроке [«Радиус обнаружения»](../radar/) турель рисовалась в
каждой ветке отдельно:

```rust
if player_distance < RADIUS {
    // Игрок внутри радиуса — красная турель.
    draw_circle(center_x, center_y, 40.0, RED);
} else {
    // Игрок снаружи — синяя турель.
    draw_circle(center_x, center_y, 40.0, BLUE);
}
```

Ветки отличаются только цветом, а остальное в них повторяется. Давай
выберем цвет один раз, а нарисуем после.

## if выдаёт значение

`if` с `else` целиком можно считать значением: какая ветка сработала,
то и получится. Это значение можно положить в переменную:

```rust
// Ветки выбирают цвет. Что выбрала сработавшая, то и попадёт в color.
let color = if player_distance < RADIUS { RED } else { BLUE };

// Рисуем один раз, цветом из переменной.
draw_circle(center_x, center_y, 40.0, color);
```

Мы уже видели такое в уроке [«Свои функции»](../functions/): там `if` с
`else` стоял последним в функции, и то, что выбрала ветка, функция
отдавала наружу. Здесь то же самое, только результат уходит не из
функции, а в переменную `color`.

## Три правила

- В обеих ветках значения одного типа: `RED` и `BLUE` оба цвета. Цвет в
  одной ветке и число в другой не получится.
- В конце ветки точку с запятой не ставим. Если поставить, ветка ничего
  не отдаст.
- `else` обязателен. Без него не сказано, что отдавать, когда условие
  неверно.

## Одно решение — несколько мест

Выгода не только в том, что код короче. Выбранный цвет можно
использовать сколько угодно раз, не повторяя условие. В демо ниже
`color` красит и турель, и контур радиуса: решение принято один раз, а
работает в двух местах.

## Что здесь происходит

- `let color = if player_distance < RADIUS { RED } else { BLUE };` — `if` с
  `else` выдаёт значение. Сработала первая ветка, и в `color` попадает
  `RED`, сработала вторая, и `BLUE`.
- `distance` — своя функция расстояния между двумя точками, как в уроке
  [«Расстояние»](../distance/), только вынесенная из `main`, как в уроке
  [«Свои функции»](../functions/). Результат записан в `player_distance`.
- `RED` и `BLUE` стоят в ветках без точки с запятой: так ветка отдаёт
  значение наружу.
- `color` используется дважды: для контура радиуса и для самой
  турели. Условие при этом проверено только один раз.
- `if` как значение работает не только для цветов, но и для любых
  значений: чисел, координат, чего угодно, лишь бы в обеих ветках
  был один и тот же тип.

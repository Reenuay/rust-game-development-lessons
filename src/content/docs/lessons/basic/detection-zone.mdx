В [«Радиусе обнаружения»](../radar/) турель смотрела только на
расстояние. В [«Секторе обнаружения»](../detection-sector/) — только
на угол, а сам сектор был неограничен по дальности, уходил за край
экрана. На деле обычно нужно и то, и другое сразу: игрок обнаружен,
если он и достаточно близко, и в пределах нужного направления.

## Оба условия сразу

Ничего нового считать не нужно — просто соединяем уже готовые
проверки через `&&`, тем же способом, что и в [«Круглых
кнопках»](../buttons/):

```rust
let inside = distance < radius && relative <= sector_span;
```

`distance` и `radius` — из «Радиуса обнаружения», `relative` и
`sector_span` — из «Сектора обнаружения». Турель срабатывает, только
когда курсор проходит обе проверки одновременно.

## Рисуем настоящий ограниченный клин

Раз сектор теперь ограничен дальностью, длинные лучи за край экрана
больше ни к чему — зону обнаружения можно нарисовать как она есть:
кусок круга радиусом `radius`. Как раз для этого в [«Дуге»](../arc/)
и разбирали `draw_arc`:

```rust
draw_arc(
    center_x,
    center_y,
    60,
    radius,
    sector_start.to_degrees(),
    3.0,
    sector_span.to_degrees(),
    GRAY,
);
```

Это единственное место во всём уроке, где нужен перевод в градусы —
`draw_arc` принимает только их, как и предупреждали в «Дуге», хотя
весь остальной код здесь по-прежнему в радианах.

Самой дуги мало — получится только изогнутый край клина, без боковых
сторон. Их дорисовываем двумя обычными `draw_line`, от центра до
каждого конца дуги, длиной ровно `radius`:

```rust
let start_x = center_x + sector_start.cos() * radius;
let start_y = center_y + sector_start.sin() * radius;
draw_line(center_x, center_y, start_x, start_y, 3.0, GRAY);

let end_x = center_x + sector_end.cos() * radius;
let end_y = center_y + sector_end.sin() * radius;
draw_line(center_x, center_y, end_x, end_y, 3.0, GRAY);
```

Дуга и два прямых отрезка вместе — ровно контур зоны обнаружения, в
точности то, что проверяет `inside`.

## Что здесь происходит

- `inside = distance < radius && relative <= sector_span` — турель
  срабатывает, только если курсор ближе радиуса **и** внутри сектора
  одновременно.
- `draw_arc(...)` рисует изогнутый край зоны — единственное место, где
  понадобился `.to_degrees()`, потому что сама функция работает только
  с градусами.
- Два `draw_line` — прямые края зоны, от центра до концов дуги, длиной
  `radius`: замыкают контур с боков.
- Турель красная внутри зоны, синяя снаружи — та же идея, что и в
  [«Радиусе обнаружения»](../radar/) и [«Секторе
  обнаружения»](../detection-sector/).

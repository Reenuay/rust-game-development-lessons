Возьмём координаты курсора из
[«Координаты мыши»](../mouse-position/) и прибавим к ним число.
Оказывается, этого достаточно, чтобы сдвинуть точку в сторону —
простая операция, но не все сразу догадываются, что она вообще для
этого годится.

К `x` прибавили положительное число — точка сдвинулась **вправо**,
прибавили отрицательное — **влево**. С `y` то же самое, но помни про
[«Координаты»](../coordinates/): ось `y` растёт вниз, а не вверх, —
поэтому прибавление к `y` сдвигает точку **вниз**, а отрицательное
число — **вверх**.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Смещение")]
async fn main() {
    loop {
        clear_background(BLACK);

        let (mouse_x, mouse_y) = mouse_position();

        // Белая точка — сама позиция курсора, просто ориентир.
        draw_circle(mouse_x, mouse_y, 8.0, WHITE);

        // Жёлтый кружок — курсор плюс смещение: правее и выше.
        draw_circle(mouse_x + 100.0, mouse_y - 50.0, 40.0, YELLOW);

        next_frame().await;
    }
}
```

Запусти как обычно:

```sh
cargo run
```

## Что здесь происходит

- `mouse_x + 100.0` — сдвигает жёлтый кружок на 100 пикселей правее
  курсора.
- `mouse_y - 50.0` — сдвигает его на 50 пикселей выше курсора: минус,
  потому что ось `y` растёт вниз.
- Белая точка нарисована прямо по `mouse_x, mouse_y`, без всякого
  смещения — она и показывает, где на самом деле находится курсор, для
  сравнения с жёлтым кружком.

В уроке [«Вращение вокруг точки»](../orbit/) разобрались, как крутить
вектор вокруг произвольной точки, а не вокруг нуля: повернуть сам
вектор, а точку прибавить уже после. Применим это на деле — сделаем
маленький кружок, вращающийся вокруг большого, как спутник вокруг
планеты.

```rust
// Точка — как в уроке «Точка и прямоугольник».
struct Point {
    x: f32,
    y: f32,
}

// Точка на окружности радиусом radius вокруг center, под углом angle.
fn orbit(center: Point, radius: f32, angle: f32) -> Point {
    // Единичный вектор — направление длиной 1, вычисленное прямо из угла.
    let direction_x = angle.cos();
    let direction_y = angle.sin();

    // Растягиваем направление до длины radius и прибавляем к center —
    // ровно тот порядок, что и в «Вращении вокруг точки».
    Point {
        x: center.x + direction_x * radius,
        y: center.y + direction_y * radius,
    }
}
```

## Что здесь происходит

- `orbit(center, radius, angle)` — считает точку на окружности в два
  шага: сперва направление `(direction_x, direction_y)` вокруг нуля,
  затем растягивает его до `radius` и прибавляет `center` — то же
  сложение, что и в уроке [«Смещение»](../offset/).
- `angle` растёт на фиксированную величину каждый кадр — `mut` и вне
  `loop`, ровно как позиция в уроке [«Погоня за мышью»](../chase/).
- Из-за перевёрнутой оси `y` (как в уроке
  [«Координаты»](../coordinates/)) вращение на экране идёт по часовой
  стрелке.
- `speed` в коде — `const SPEED`, а не переменная внутри `loop`:
  значение одно и то же на каждом кадре, пока ты сам его не изменишь,
  поэтому это константа, как в уроке [«Константы»](../constants/).

В уроке [«Цикл for»](../for-loop/) количество кружков было зашито в код —
ровно пять. Цикл там избавил нас от пяти одинаковых строк `draw_circle`,
но число кружков всё равно было известно заранее, ещё когда мы писали
код.

У `for` есть вторая, более важная сила: один и тот же код работает для
**любого** количества, каким бы оно ни оказалось. Циклу всё равно,
сколько раз повторяться — пять, один или двадцать: он просто проходит
диапазон `0..COUNT`, сколько бы чисел в нём ни было.

## Умещаем любое количество в одну ширину

В уроке [«Цикл for»](../for-loop/) шаг между кружками был фиксированным
числом — годится, пока кружков немного. Но раз количество теперь может
быть любым, с фиксированным шагом кружки рано или поздно уедут за край
экрана. Удобнее не задавать шаг заранее, а вычислять его так, чтобы
сколько бы кружков ни было, все они равномерно уместились в одну и ту
же ширину `WIDTH`. Для этого саму ширину нужно поделить не на
количество кружков, а на количество промежутков между ними — а
промежутков всегда на один меньше, чем кружков:

```rust
// Промежутков между кружками на один меньше, чем самих кружков.
let step = WIDTH / (COUNT - 1) as f32;
```

Дальше удобно отсчитывать `x` не от края, а от среднего кружка — тогда
слева и справа от него всегда поровну шагов, сколько бы кружков ни
было:

```rust
// Средний индекс — точка отсчёта, от которой смещается каждый кружок.
let mid = (COUNT - 1) as f32 / 2.0;
let x = center_x + (i as f32 - mid) * step;
```

Для пяти кружков (`i` от `0` до `4`) средний — третий, `mid = 2.0`.

## Один кружок — особый случай

Если кружок всего один, встаёт вопрос: где его рисовать? Шаг между
кружками считался как `WIDTH / (COUNT - 1)` — а при `COUNT = 1` это
`WIDTH / 0`, то самое деление на ноль, о котором был отдельный урок
[«Деление на ноль»](../divide-by-zero/).

```rust
// Считаем шаг, только если кружков больше одного — иначе делили бы на ноль.
let step = if COUNT > 1 { WIDTH / (COUNT - 1) as f32 } else { 0.0 };
```

Когда кружок один, шаг ни на что не влияет: `mid` тоже равен `0.0`, и
единственный кружок встаёт ровно в `center_x`, точно по центру.

## Что здесь происходит

- `COUNT` — то же самое число, что и в уроке [«Цикл for»](../for-loop/),
  но теперь его задаёт поле ниже, а не фиксированное значение в коде.
- `for i in 0..COUNT` не изменился ни на символ — весь урок как раз о
  том, что этому циклу не нужно знать заранее, сколько кружков
  рисовать, чтобы правильно отработать.
- Поставь `count` в 1 — код не падает и не ведёт себя странно: он
  просто рисует один кружок по центру, потому что мы заранее защитили
  деление от нуля.

Прежде чем двигаться дальше, остановимся на секунду и разберём один
приём, который уже пригодился в уроке ["Ввод с клавиатуры"](../input/),
но остался без объяснения.

## Было

В уроке ["Ввод с клавиатуры"](../input/) код выглядел так:

```rust
if is_key_down(KeyCode::Up) {
    draw_circle(screen_width() / 2.0, screen_height() / 2.0, 100.0, YELLOW);
}
```

`screen_width()` и `screen_height()` возвращают ширину и высоту
игрового окна в пикселях. Эта строка — внутри `loop`, а значит
выполняется заново на каждом кадре: несколько десятков раз в секунду
Rust заново спрашивает "какая ширина окна?" и заново делит её пополам.
Но пока игра работает, ширина окна не меняется — ответ каждый раз один
и тот же.

## Переменная

Раз ответ не меняется, можно посчитать его один раз и запомнить. Для
этого в Rust есть `let`:

```rust
let center_x = screen_width() / 2.0;
```

Это создаёт переменную с именем `center_x` и кладёт в неё результат
выражения справа. Дальше в коде можно писать просто `center_x` вместо
`screen_width() / 2.0` — Rust подставит уже готовое значение.

## Применяем к нашему коду

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Ввод с клавиатуры")]
async fn main() {
    let center_x = screen_width() / 2.0;
    let center_y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        if is_key_down(KeyCode::Up) {
            draw_circle(center_x, center_y, 100.0, YELLOW);
        }

        next_frame().await;
    }
}
```

`center_x` и `center_y` теперь считаются один раз, до `loop`, а внутри
цикла только используются. На экране ничего не изменилось — тот же
кружок по той же клавише:

## Что здесь происходит

- `let center_x = screen_width() / 2.0;` — стоит до `loop`, поэтому
  выполняется один раз при запуске игры, а не на каждом кадре.
- Имя `center_x` говорит само за себя — `draw_circle(center_x,
  center_y, ...)` читается проще, чем `draw_circle(screen_width() /
  2.0, screen_height() / 2.0, ...)`.
- `center_x` и `center_y` — неизменяемые переменные: получили значение
  один раз и дальше в игре не меняются.

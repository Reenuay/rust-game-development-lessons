Прежде чем двигаться дальше, остановимся на секунду и разберём один
приём, который уже пригодился в уроке ["Ввод с клавиатуры"](../input/),
но остался без объяснения.

## Было

В уроке ["Ввод с клавиатуры"](../input/) код выглядел так:

```rust
// Стрелка вверх зажата — рисуем круг.
if is_key_down(KeyCode::Up) {
    draw_circle(screen_width() / 2.0, screen_height() / 2.0, 100.0, YELLOW);
}
```

`screen_width()` и `screen_height()` возвращают ширину и высоту
игрового окна в пикселях. Эта строка — внутри `loop`, а значит
выполняется заново на каждом кадре: несколько десятков раз в секунду
Rust заново спрашивает "какая ширина окна?" и заново делит её пополам.

Окно вообще-то можно растянуть мышкой прямо во время игры — тогда
ширина по-настоящему изменится. Но наша простая игра размер окна
никак не отслеживает и не подстраивается под него, так что для нас
проще договориться: пока игра работает, окно остаётся того же
размера, каким было в начале. А раз ответ не меняется, спрашивать
"какая ширина окна?" заново на каждом кадре — лишняя работа.

## Переменная

Раз ответ не меняется, можно посчитать его один раз и запомнить:

```rust
// Ширина экрана, поделённая пополам — центр по горизонтали.
let center_x = screen_width() / 2.0;
```

Разберём по кусочкам. `let` — ключевое слово: слово, уже занятое Rust
под особый смысл — "дальше будет новая переменная". Оно всегда одно и
то же и придумано не нами, поэтому его нельзя взять как имя для своей
переменной — Rust решит, что это снова та самая команда, а не имя.
После него через пробел — имя, какое захочешь, здесь это `center_x`. А
`=` — не "равно" из математики, а **оператор присваивания**: "посчитай
то, что справа, и положи результат в то, что слева".

Переменную проще всего представить как подписанную корзинку:
присваивание кладёт в неё значение один раз, а дальше по коду
достаточно написать имя — `center_x` — и оттуда снова достанется то же
самое значение, без необходимости считать заново.

## Применяем к нашему коду

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

#[macroquad::main("Ввод с клавиатуры")]
async fn main() {
    // Центр экрана — считаем один раз, до loop.
    let center_x = screen_width() / 2.0;
    let center_y = screen_height() / 2.0;

    loop {
        clear_background(BLACK);

        // Стрелка вверх зажата — рисуем круг.
        if is_key_down(KeyCode::Up) {
            draw_circle(center_x, center_y, 100.0, YELLOW);
        }

        next_frame().await;
    }
}
```

`center_x` и `center_y` теперь считаются один раз, до `loop`, а внутри
цикла только используются. На экране ничего не изменилось — тот же
кружок по той же клавише:

## Что здесь происходит

- `let center_x = screen_width() / 2.0;` — стоит до `loop`, поэтому
  выполняется один раз при запуске игры, а не на каждом кадре.
- Имя `center_x` говорит само за себя — `draw_circle(center_x,
  center_y, ...)` читается проще, чем `draw_circle(screen_width() /
  2.0, screen_height() / 2.0, ...)`.
- `center_x` и `center_y` — неизменяемые переменные: получили значение
  один раз и дальше в игре не меняются.

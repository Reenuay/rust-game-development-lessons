В уроке [«Разноцветные кружки»](../colors/) каждый кружок — это кортеж из
трёх элементов: `(f32, f32, Color)`. Добавим кружкам ещё и радиус —
четвёртый элемент, `(f32, f32, f32, Color)`.

У элементов кортежа есть номера — `.0`, `.1`, `.2`, `.3` — и достать
элемент по номеру можно прямо через точку:

```rust
let circle: (f32, f32, f32, Color) = (120.0, 80.0, 30.0, YELLOW);

// .0, .1, .2, .3 — элементы кортежа по порядку.
draw_circle(circle.0, circle.1, circle.2, circle.3);
```

Можно вместо этого разобрать кортеж на отдельные переменные — так,
как мы всегда делали с `mouse_position()`:

```rust
let (x, y, radius, color) = circle;
draw_circle(x, y, radius, color);
```

Читается лучше, но разбирать приходится заново на каждом месте, где
кортеж используется — а в уроке [«Список кружков»](../list/) таких мест
несколько: и когда кружок только создаётся, и в цикле, где рисуется
каждый уже сохранённый. С парой чисел это было не в тягость. С
четырьмя элементами — уже утомительно, и легко перепутать местами
два поля одного типа при разборе: например, `radius` и `x`, оба
`f32`, компилятор такую ошибку даже не заметит.

## struct — свой именованный тип

Хочется чего-то среднего: чтобы поля были видны по имени, но
разбирать кортеж заново каждый раз не приходилось — сразу пользоваться
именем поля, как у массива есть индекс, доступный прямо на месте, без
подготовки. Кортеж для этого не подходит: у него просто нет имён для
полей, только номера. В Rust имена полей нельзя придумать на ходу,
прямо в месте, где создаётся значение — сначала нужно объявить форму
структуры отдельно, один раз, а уже потом создавать по ней значения:

```rust
struct Circle {
    x: f32,
    y: f32,
    radius: f32,
    color: Color,
}
```

Значение такого типа создаётся по имени, с явным указанием, что куда
идёт:

```rust
let circle = Circle { x: 120.0, y: 80.0, radius: 30.0, color: YELLOW };

// Каждое поле теперь видно по имени, а не по номеру.
draw_circle(circle.x, circle.y, circle.radius, circle.color);
```

`Color` тут — тот же тип, что и в уроке [«Разноцветные
кружки»](../colors/): тип значений вроде `YELLOW` и `RED`.

## Свои функции

В уроке [«Свои функции»](../functions/) мы уже выносили похожий кусок —
расстояние между двумя точками — в отдельную функцию `direction`.
Сделаем то же самое здесь: и подсчёт расстояния для радиуса, и выбор
случайного цвета, стоит вынести из `loop`, чтобы не повторять один и
тот же код на каждом кадре:

```rust
// Своя функция: расстояние между двумя точками, как в уроке «Расстояние».
fn distance(from_x: f32, from_y: f32, to_x: f32, to_y: f32) -> f32 {
    let dx = to_x - from_x;
    let dy = to_y - from_y;
    (dx * dx + dy * dy).sqrt()
}

// Своя функция: случайный цвет из списка COLORS.
fn random_color() -> Color {
    COLORS[rand::gen_range(0, COLORS.len())]
}
```

`COLORS` внутри `random_color` — та же константа, что объявлена
снаружи, в начале файла: раз она `const`, её видно из любой функции,
не только из `main`, и передавать её отдельным параметром не нужно.

## Попробуй сам

Зажми кнопку мыши в любой точке и, не отпуская, потяни в сторону —
радиус кружка растёт вслед за мышью. Отпусти — кружок сохранится со
случайным цветом. Радиус не бывает меньше 5 пикселей, а максимума у
него нет.

## Код

Замени содержимое `src/main.rs` на это:

```rust title="src/main.rs"
use macroquad::prelude::*;

// Фиксированный список цветов, из которого выбираем случайный.
const COLORS: [Color; 4] = [YELLOW, RED, GREEN, BLUE];

// Один кружок: положение, радиус и цвет вместе, под понятными именами.
struct Circle {
    x: f32,
    y: f32,
    radius: f32,
    color: Color,
}

// Своя функция: расстояние между двумя точками, как в уроке «Расстояние».
fn distance(from_x: f32, from_y: f32, to_x: f32, to_y: f32) -> f32 {
    let dx = to_x - from_x;
    let dy = to_y - from_y;
    (dx * dx + dy * dy).sqrt()
}

// Своя функция: случайный цвет из списка COLORS.
fn random_color() -> Color {
    COLORS[rand::gen_range(0, COLORS.len())]
}

#[macroquad::main("Свои структуры")]
async fn main() {
    // Список уже нарисованных кружков — сначала пустой.
    let mut circles: Vec<Circle> = Vec::new();

    // Точка, где начали тянуть радиус текущего кружка.
    let mut drag_x = 0.0;
    let mut drag_y = 0.0;

    loop {
        clear_background(BLACK);

        // Координаты мыши прямо сейчас.
        let (mouse_x, mouse_y) = mouse_position();

        // Кнопка мыши только что нажата — запоминаем точку начала.
        if is_mouse_button_pressed(MouseButton::Left) {
            drag_x = mouse_x;
            drag_y = mouse_y;
        }

        // Радиус не может быть меньше 5 — иначе кружок пропадёт из виду.
        let radius = distance(drag_x, drag_y, mouse_x, mouse_y).max(5.0);

        // Кнопка зажата — показываем, каким получится кружок.
        if is_mouse_button_down(MouseButton::Left) {
            draw_circle(drag_x, drag_y, radius, YELLOW);
        }

        // Кнопку только что отпустили — сохраняем готовый кружок.
        if is_mouse_button_released(MouseButton::Left) {
            circles.push(Circle { x: drag_x, y: drag_y, radius, color: random_color() });
        }

        // Рисуем все уже сохранённые кружки.
        for circle in &circles {
            draw_circle(circle.x, circle.y, circle.radius, circle.color);
        }

        next_frame().await;
    }
}
```

```sh
cargo run
```

## Что здесь происходит

- `struct Circle { ... }` объявляет новый тип данных с именованными
  полями — свою собственную структуру, а не встроенную, как `f32`
  или `Color`.
- `Circle { x: ..., y: ..., radius: ..., color: ... }` создаёт
  значение этого типа — поля перечисляются по имени, порядок не
  важен.
- `circle.radius`, `circle.color` — доступ к полю по имени, вместо
  `.0`, `.1`, `.2`, `.3` у кортежа, и без того, чтобы сначала разбирать
  всю структуру на отдельные переменные — поле берётся прямо там, где
  нужно.
- `radius` в `Circle { ..., radius, ... }` — сокращённая запись: раз
  локальная переменная называется так же, как поле, `radius: radius`
  можно не писать целиком.
- `distance(...)` вернула число, а `.max(5.0)` не даёт этому числу
  стать радиусом меньше 5 — тот же приём ограничения снизу, что и в
  уроке [«Сколько угодно кружков»](../any-count/), только здесь
  верхней границы нет вовсе.
- `distance` и `random_color` вынесены из `loop` по тому же принципу,
  что и в уроке [«Свои функции»](../functions/): каждая — законченный
  кусок математики со своим именем, и в `loop` вместо него остаётся
  один короткий вызов вместо нескольких строк.
- `Vec<Circle>` — тот же растущий список из урока [«Список
  кружков»](../list/), просто элементы теперь — не кортежи, а
  значения `Circle`.

Давай сделаем так, чтобы турель стреляла сама, пока зажата кнопка
мыши. В уроке [«Стрельба по мишеням»](../targets/) на каждую пулю
нужен был отдельный клик, а теперь будет достаточно просто держать
кнопку.

## Зажата, а не нажата

Раньше выстрел происходил по `is_mouse_button_pressed`. Она верна
только на одном кадре, в тот момент, когда кнопку нажали. Нам нужна
`is_mouse_button_down` из урока [«Клик мышью»](../mouse-click/): она
верна на каждом кадре, пока кнопка зажата.

Но если просто заменить одну функцию на другую, турель будет выпускать
по пуле на каждом кадре, и получится сплошная струя. Между выстрелами
нужна пауза.

## Счётчик перезарядки

Заведём число `cooldown`, то есть сколько кадров осталось подождать до
следующего выстрела. Каждый кадр оно уменьшается на единицу, пока не
дойдёт до нуля. Ноль значит «можно стрелять». После выстрела мы снова
кладём в счётчик `SHOOT_INTERVAL`, и отсчёт начинается заново:

```rust
// Счётчик идёт к нулю и ниже нуля не опускается.
if cooldown > 0 {
    cooldown -= 1;
}

// Кнопка зажата и ждать больше не нужно — стреляем и запускаем отсчёт заново.
if is_mouse_button_down(MouseButton::Left) && cooldown == 0 {
    cooldown = SHOOT_INTERVAL;
}
```

Ниже нуля счётчик опускаться не должен: он считает, сколько кадров
осталось ждать, а ждать «минус три кадра» нельзя. Поэтому единицу мы
вычитаем, только пока `cooldown` больше нуля.

В начале `cooldown` равен нулю, поэтому первый выстрел происходит сразу,
как только ты зажал кнопку. Отпустишь кнопку, и счётчик всё равно дойдёт
до нуля сам, так что следующее нажатие выстрелит сразу, если пауза уже
закончилась.

Всё остальное нам уже знакомо. Пули лежат в `HashMap` со своими ID, как
в уроке [«Стрельба по мишеням»](../targets/), и пропадают за краем
экрана тем же способом.

## Что здесь происходит

- `is_mouse_button_down` верна на каждом кадре, пока кнопка зажата. А
  `is_mouse_button_pressed` срабатывает один раз, в момент нажатия.
- `cooldown` показывает, сколько кадров осталось ждать. Объявлен он до
  `loop`, чтобы помнить своё значение от кадра к кадру.
- `if cooldown > 0 { cooldown -= 1; }` уменьшает счётчик до нуля и
  останавливает его там.
- `&& cooldown == 0` разрешает выстрел только тогда, когда счётчик дошёл
  до нуля.
- `cooldown = SHOOT_INTERVAL` запускает отсчёт заново сразу после
  выстрела.
- `SHOOT_INTERVAL` задаёт паузу в кадрах: чем меньше число, тем чаще
  выстрелы. При `1` турель стреляет на каждом кадре.
- `bullets` — это `HashMap<u32, Bullet>`, а `next_id` выдаёт каждой новой
  пуле свой ID. Пули, вылетевшие за край, попадают в `bullets_to_remove`
  и удаляются после того, как мы закончили читать `bullets`.

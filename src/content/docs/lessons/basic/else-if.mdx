Давай сделаем полоску здоровья из урока
[«Полоска здоровья»](../health-bar/) трёхцветной: зелёной, пока
здоровья много, жёлтой, когда его осталось поменьше, и красной, когда
оно почти кончилось.

## Больше двух вариантов

`if` с `else` выбирает из двух вариантов. Когда их три, между ними можно
вставить ещё одну проверку: `else if`, то есть «а если нет, то проверь
вот это». Выбор получается таким же, как в уроке
[«if как значение»](../if-value/), только вариантов теперь три:

```rust
// Много здоровья — зелёный, иначе средне — жёлтый, иначе мало — красный.
let color = if fraction > GOOD_HEALTH {
    GREEN
} else if fraction > LOW_HEALTH {
    YELLOW
} else {
    RED
};
```

`GOOD_HEALTH` равно `0.6`, а `LOW_HEALTH` равно `0.3`: зелёный выше 60
процентов, жёлтый от 30 до 60, красный ниже.

## Проверяются по очереди

Условия проверяются сверху вниз. Как только одно оказалось верным, берём
его ветку, а остальные пропускаем, даже если они тоже верны. Осталось 80
процентов здоровья: первое условие `fraction > GOOD_HEALTH` верно,
получается зелёный, и до второго дело не доходит.

Поэтому порядок проверок важен. Что будет, если поменять их местами:

```rust
// Неправильный порядок: зелёного не получится никогда.
let color = if fraction > LOW_HEALTH {
    YELLOW
} else if fraction > GOOD_HEALTH {
    GREEN
} else {
    RED
};
```

80 процентов здоровья больше `0.3`, поэтому сработает первая проверка и
полоска станет жёлтой, а до зелёной дело не дойдёт. Проверять надо от
самого строгого условия к самому мягкому.

## Правила те же

Всё, как в уроке [«if как значение»](../if-value/): во всех ветках
значения одного типа, на конце веток нет точки с запятой, а последний
`else` обязателен. `else if` можно добавлять сколько нужно.

Он работает и в обычном `if`, где ветки не выдают значение, а что-то
делают.

## Что здесь происходит

- `GOOD_HEALTH` и `LOW_HEALTH` — доли здоровья, по которым цвет
  меняется. Это константы, как в уроке [«Константы»](../constants/).
- `if fraction > GOOD_HEALTH { GREEN }` — первое условие. Если здоровья
  больше 60 процентов, цвет зелёный.
- `else if fraction > LOW_HEALTH { YELLOW }` — проверяется, только если
  первое условие не сработало. Если здоровья больше 30 процентов,
  цвет жёлтый.
- `else { RED }` — всё остальное: здоровья 30 процентов или меньше.
- Условия проверяются сверху вниз, срабатывает первое верное. Поэтому
  их записывают от самого строгого к самому мягкому.

В уроке [«Турель стреляет очередью»](../turret-volley/) список пуль
рос без остановки — это было осознанным упрощением. Пора его убрать:
пули, улетевшие достаточно далеко, должны пропадать из списка.

## Видимая граница вместо настоящего края экрана

Если убирать пули ровно по краю экрана, это будет незаметно — пуля и
так пропадала бы из вида, покидая экран. Чтобы увидеть **сам момент**
исчезновения, возьмём границу заметно меньше экрана и нарисуем её
контур:

```rust
draw_rectangle_lines(view_x, view_y, view_width, view_height, 8.0, LIGHTGRAY);
```

`draw_rectangle_lines` — то же самое, что `draw_circle_lines` в уроке
[«Расстояние»](../distance/), только контур не круга, а
прямоугольника. Демка ниже даёт настроить отступ этой границы от
края экрана: сделай его нулевым — и граница дойдёт до настоящего
края.

## Проверка попадания — своей функцией

Считать, внутри ли точка прямоугольника, мы уже умеем — четыре
условия через `&&`, как в уроке [«Прямоугольные
кнопки»](../rect-buttons/). На этот раз вынесем это в отдельную
функцию, раз проверять предстоит для каждой пули на каждом кадре:

```rust
fn inside_rectangle(x: f32, y: f32, rect_x: f32, rect_y: f32, rect_width: f32, rect_height: f32) -> bool {
    x >= rect_x && x <= rect_x + rect_width && y >= rect_y && y <= rect_y + rect_height
}
```

## Забираем список в собственность

У `for` до сих пор было два варианта: `&bullets` — одолжить список
только для чтения, ничего не меняя, и `&mut bullets` — одолжить его
для изменения на месте. Но у обоих есть общая черта: сам список
`bullets`, сколько бы элементов в нём ни было, остаётся тем же самым
списком до и после цикла — их количество через такой `for` не
поменять.

Есть третий вариант — `for bullet in bullets`, вовсе без `&`. Он не
одалживает список, а **забирает его в собственность целиком**. Каждый
элемент по очереди становится собственностью переменной `bullet`
внутри цикла, а исходная переменная `bullets` после такого цикла
больше не существует — воспользоваться ей ещё раз нельзя.

Именно это нам и нужно: мы хотим не просто изменить пули на месте, а
**выбросить** часть из них — а количество элементов через `&mut`
не поменять. План такой: забираем старый список целиком, для каждой
пули решаем, оставить её или нет, и если да — добавляем в новый,
изначально пустой список. Пули, которые не добавили никуда, просто
забываются вместе со старым списком.

```rust
let mut kept_bullets: Vec<Bullet> = Vec::new();

for mut bullet in bullets {
    bullet.x += bullet.direction_x * SPEED;
    bullet.y += bullet.direction_y * SPEED;

    if inside_rectangle(bullet.x, bullet.y, view_x, view_y, view_width, view_height) {
        draw_circle(bullet.x, bullet.y, 8.0, YELLOW);
        kept_bullets.push(bullet);
    }
}

bullets = kept_bullets;
```

Обрати внимание на `for mut bullet in bullets` — здесь `mut` стоит
перед `bullet`, а не перед `bullets`. В `for bullet in &mut bullets`
из прошлого урока `bullet` был **ссылкой** на пулю внутри списка, и
эта ссылка уже разрешала менять `bullet.x`/`bullet.y`. Здесь же
`bullet` — не ссылка, а сама пуля целиком, её полноценный владелец, и,
чтобы менять её поля, переменная `bullet` должна быть объявлена
мутабельной — той же самой `mut`, что и в [«Изменяемых
переменных»](../mutability/).

## Что здесь происходит

- `draw_rectangle_lines` рисует только контур границы обзора — сам
  прямоугольник не закрашен, чтобы не закрывать пули и турель.
- `inside_rectangle(...)` — своя функция, проверяющая попадание точки
  в прямоугольник; та же логика, что и в уроке [«Прямоугольные
  кнопки»](../rect-buttons/), просто теперь она переиспользуется, а не
  прописана прямо в `loop`.
- `for mut bullet in bullets` забирает список в собственность: старая
  переменная `bullets` после цикла недоступна, поэтому в конце ей
  присваивается новое значение — `kept_bullets`.
- Пуля добавляется в `kept_bullets`, только если прошла проверку
  `inside_rectangle` — не прошедшие никуда не попадают и пропадают
  вместе со старым списком.
- `margin`, заданный полем ниже, определяет отступ границы от краёв
  экрана — на `0` она сливается с настоящим краем экрана.
